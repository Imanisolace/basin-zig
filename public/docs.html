Basin Data Integrity API Docs

Basin is an ultra-fast engine for creating tamper-proof logs, audit trails, and financial ledgers.

Base URL: https://railway.app

Auth: Send x-api-key header

1. Get API Key

POST /apikey
{ "email": "you@email.com", "user_id": "clerk_123" }

2. Commit Data to Ledger (Generate Integrity Receipt)

Secure your log entry or transaction payload. Basin instantly locks it into a mathematically unalterable timeline.

curl -X POST https://railway.app/prove \
-H "x-api-key: zk_YOUR_KEY" \
-H "Content-Type: application/json" \
-d '{"item":"transaction_or_log_data"}'

Response: { root, proof, target_index, valid }

3. Verify Data Authenticity (Audit Check)

Instantly prove that your historical data has not been modified, deleted, or tampered with.

curl -X POST https://railway.app/verify \
-H "x-api-key: zk_YOUR_KEY" \
-H "Content-Type: application/json" \
-d '{ "root": "...", "item": "transaction_or_log_data", "target_index": 0, "proof": [...] }'

4. Check Usage

curl https://railway.app/usage \
-H "x-api-key: zk_YOUR_KEY"
