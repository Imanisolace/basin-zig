Basin API Documentation

Basin is an ultra-fast, edge-optimized data integrity engine. Secure your application logs, financial entries, and database states with mathematically unalterable audit trails.

Base URL: https://basin-zig-production.up.railway.app

Auth: Send x-api-key header

1. Get Your Free API Key

Initialize an account and get a secure access token instantly.

POST /apikey
{ "email": "you@email.com", "user_id": "clerk_123" }

2. Commit Data to the Immutable Ledger

Append a data entry to your secure timeline. Basin hashes the entry into a cryptographically sealed state structure and returns an integrity receipt.

curl -X POST https://basin-zig-production.up.railway.app/prove \
-H "x-api-key: zk_YOUR_KEY" \
-H "Content-Type: application/json" \
-d '{"item":"transaction_or_log_payload"}'

Response: { root, proof, target_index, valid }

3. Verify Data Authenticity (Audit Check)

Instantly confirm that a specific log or database entry has never been altered, deleted, or tampered with by checking it against the global integrity root.

curl -X POST https://basin-zig-production.up.railway.app/verify \
-H "x-api-key: zk_YOUR_KEY" \
-H "Content-Type: application/json" \
-d '{ "root": "...", "item": "transaction_or_log_payload", "target_index": 0, "proof": [...] }'

4. Check API Usage & Metrics

Monitor your active throughput and ledger consumption metrics.

curl https://basin-zig-production.up.railway.app/usage \
-H "x-api-key: zk_YOUR_KEY"
